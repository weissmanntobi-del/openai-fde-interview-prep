# Seven-day focused practice plan

| Day | Main task | Deliverable |
| --- | --- | --- |
| 1 | Map public role responsibilities to past projects | Three evidence-backed delivery stories |
| 2 | Implement idempotency coding exercise | Tests, failure cases, design notes |
| 3 | Run eval lab and correct known issue | Before/after results + error analysis |
| 4 | Design safe agent tool gateway | Diagram + 5 abuse tests |
| 5 | Work claims copilot case | Architecture, MVP scope, eval plan |
| 6 | Run discovery simulation + incident drill | Scope memo and incident report |
| 7 | Complete timed mock + rubric | Recorded score and next 2-week backlog |

Try to produce one tangible artifact each day. More documents are not a substitute for a working test, clear business metric, or customer-specific judgment.
