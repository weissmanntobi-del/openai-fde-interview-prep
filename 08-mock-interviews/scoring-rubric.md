# Evaluation rubric (100 points)

| Dimension | Points | Excellent evidence |
| --- | ---: | --- |
| Problem framing + discovery | 15 | Clarifies actual workflow, baseline, assumptions, risks |
| Delivery scope + judgment | 15 | Defensible MVP, sequencing, transparent trade-offs |
| Technical correctness | 20 | Working code/architecture, edge cases, tests |
| AI evaluation | 20 | Representative cases, regression, error analysis, criteria |
| Security + reliability | 15 | Authorization boundaries, failure modes, rollback |
| Communication + adoption | 15 | Stakeholder clarity, adoption metrics, reusable feedback |

**Suggested self-assessment, not an employer standard:** 85–100 strong; 70–84 targeted improvement; <70 rebuild fundamentals. Review critical safety issues separately regardless of total score. For each dimension, cite one artifact or observation and one specific improvement action.
