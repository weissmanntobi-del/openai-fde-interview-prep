# Original mock interview menu

These are practice simulations, **not confirmed OpenAI interview rounds**.

| Mock | Minutes | Deliverable |
| --- | ---: | --- |
| Code review + backend reliability | 50 | Correct, tested idempotent processor |
| AI eval diagnosis | 45 | Failure taxonomy and release decision |
| Customer discovery | 30 | MVP charter, measurable success criteria |
| AI system design | 60 | Architecture, controls, rollout plan |
| Production incident | 35 | Triage, comms, prevention |
| Stakeholder trade-off | 30 | Written sponsor update + adjusted plan |

Use the [rubric](scoring-rubric.md) and explain each choice out loud (or in writing). Timebox practice and record evidence, not just confidence.
