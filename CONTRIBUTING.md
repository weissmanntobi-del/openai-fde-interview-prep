# Contributing

Welcome corrections, test improvements, clearly labeled original problems, and reproducible deployment case studies. Open an issue describing context and expected outcome before large PRs. Contributions must not contain confidential interview material, employee-only evaluation content, customer secrets, or unauthorized personal data.

For code changes, run `python -m unittest discover -s tests -v` and document expected behavior. Be explicit about assumptions and avoid claiming that a prompt is verified as used by OpenAI. Contributors agree to license submitted content under MIT.
